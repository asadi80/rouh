# من أين يقرأ الموقع بياناته؟

هذا الموقع (`clinic-app`) لا يتصل بأي قاعدة بيانات مباشرة. كل بياناته (الأطباء،
الخدمات، أوقات العمل، معلومات العيادة، الإعلانات) تُقرأ عبر طلبات HTTP عادية من
سيرفر Node.js/Express المنفصل في مشروع `rouh-platform/server`.

## الإعداد
انسخ `.env.example` إلى `.env` وضع رابط السيرفر:

```
VITE_API_URL=https://api.rouh.ly
```

## ماذا لو لم يُضبط الرابط، أو تعذّر الوصول للسيرفر؟
الموقع لا ينهار — يعرض بيانات ثابتة احتياطية من `src/data/clinicData.js` بدلًا
من ذلك، مع طباعة تحذير في console. بمجرد ضبط `VITE_API_URL` بشكل صحيح، يعرض
الموقع البيانات الحقيقية القادمة من لوحة التحكم مباشرة.

## لوحة التحكم (تعديل المحتوى)
لوحة التحكم أصبحت تطبيقًا منفصلًا بالكامل (`rouh-platform/client`)، وليست جزءًا
من هذا المشروع. أي تعديل تجريه هناك (إضافة طبيب، تعديل الأوقات، إلخ) ينعكس
مباشرة هنا فور تحديث الصفحة، لأن كليهما يقرأ من نفس سيرفر الـ API.
