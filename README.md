# موقع عيادة الشفاء للطب النفسي

تطبيق ويب تقدّمي (PWA) — React + Vite — بواجهة عربية بالكامل (RTL)، متجاوب مع جميع المقاسات (جوال / تابلت / كمبيوتر)، مبني على هوية شعار العيادة.

## المحتوى
- الصفحة الرئيسية (Hero) باسم العيادة وشعارها
- قسم الأطباء المتاحين مع جدول مواعيد كل طبيب وزر حجز عبر واتساب
- قسم أوقات العمل الأسبوعية (مع تمييز يوم اليوم تلقائيًا)
- قسم الموقع: خريطة Google مضمّنة، بالضغط عليها يفتح المسار في تطبيق/موقع خرائط Google
- قسم منصات التواصل الاجتماعي (روابط قابلة للتعديل)
- شريط إجراءات سريعة ثابت أسفل الشاشة على الجوال (اتصال / واتساب / حجز / الموقع)
- يعمل كـ PWA: يمكن "تثبيته" على الجوال أو الكمبيوتر ويعمل بدون إنترنت بعد أول زيارة

## التشغيل محليًا
```bash
npm install
npm run dev
```
افتح الرابط الذي يظهر في الطرفية (عادة http://localhost:5173).

## بناء نسخة الإنتاج
```bash
npm run build
npm run preview   # لمعاينة نسخة الإنتاج محليًا
```
الناتج النهائي يكون داخل مجلد `dist` — ارفعه إلى أي استضافة (Netlify, Vercel, GitHub Pages, أو أي سيرفر ويب عادي).

## تعديل محتوى الموقع (الأهم)
كل بيانات العيادة القابلة للتعديل موجودة في ملف واحد:

```
src/data/clinicData.js
```

من هذا الملف يمكنك تعديل:
- **اسم العيادة، الوصف، رقم الهاتف، واتساب، البريد، العنوان**
- **رابط خرائط Google**: افتح خرائط Google → ابحث عن موقع عيادتك → اضغط "مشاركة" → انسخ الرابط وضعه في `googleMapsUrl`. أما `googleMapsEmbedUrl` فهو رابط التضمين (Embed) لعرض الخريطة داخل الصفحة (من نفس نافذة المشاركة اختر "تضمين خريطة" وانسخ رابط الـ src فقط)
- **روابط منصات التواصل الاجتماعي** (`socialLinks`)
- **أوقات العمل الأسبوعية** (`workingHours`)
- **قائمة الأطباء وجداولهم** (`doctors`) — أضف طبيبًا جديدًا بنسخ نفس تنسيق العنصر وتعديل البيانات

## تغيير الشعار
الشعار موجود في `src/assets/logo.png`. لتغييره:
1. استبدل الملف بنفس الاسم، أو
2. غيّر مسار الاستيراد في `src/components/Header.jsx` و`src/components/Hero.jsx` و`src/components/Footer.jsx`

كما يجب إعادة توليد أيقونات PWA (داخل `public/icons`) بنفس المقاسات: 192×192، 512×512، وأيقونة maskable 512×512، بالإضافة إلى `public/favicon.png` (32×32).

## الألوان والخطوط
جميع الألوان معرّفة كمتغيرات CSS في `src/styles/tokens.css` (مأخوذة من ألوان الشعار: الأزرق المخضر الداكن والأخضر الفاتح، على خلفية بيضاء). الخط الأساسي "Tajawal" وخط العناوين "El Messiri" (خطوط عربية من Google Fonts، محمّلة في `index.html`).

## ملاحظة حول التثبيت كتطبيق
بعد رفع الموقع على نطاق (domain) فعلي بشهادة HTTPS، سيتمكن الزوار من "تثبيت" الموقع كتطبيق من المتصفح (زر "تثبيت التطبيق" / "Add to Home Screen").
